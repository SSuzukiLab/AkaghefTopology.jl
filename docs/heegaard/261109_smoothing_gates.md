# LC の平滑化入口とゲート

2026-11-09 の所有者の続行指示による修正。破綻は図から読み取れる対象が入力と異なることであり、余計な交差、穴への侵入、Kを越える逸脱を含む。見づらさだけでは破綻としない。

## LC gate

配置は座標を変更せず、各描画曲線に沿う符号付き交点列を `crossing_structure` に付加する。符号はLCの符号である。外側の面では既存の円板配置と放射写像がそれぞれ向きを反転し、出力平面ではLCの向きになるため、ここで符号を再反転しない。共有節の交点ラベル・訪問順序・交点周りの半辺の巡回順序をこの列から作る。再標本化後の余計な交差を基準に採用しない。

従来の線分内部交差で見つからなかった訪問だけ、標本点上の交点も節へ登録する。交点はすべて共有頂点として扱い、それ以外の線分交差・接触・重なりをゲートで拒否する。既存の古い配置JSONに交点列がない場合には従来の共有点の同定を使うが、曲線間の交点を持つ新しいLC配置の既定経路には交点列がある。

## Resampling gate

従来の標本化を先に試し、交差構造・穴・正方形境界のゲートを適用する。問題のある新しい線分が飛び越した入力頂点を保持して再標本化する。問題のない入力の標本点を変えず、問題のある区間だけを細分する。

## Boundary gate

穴の検査には固定端点につながる線分も含める。正方形では曲線の頂点を閉正方形内に保つ（正方形は凸なので線分も内部にある）。ゲート違反がある試行は従来の凍結・刻み縮小の経路に戻す。張力・曲げ・反発の式と諸元は変更しない。

まず参照実装と同じ提案・凍結順序で候補を作り、その最終候補に強化したLCゲートを適用する。通れば旧来と同じ座標を受理し、違反時には候補と運動量を戻して強化したゲートによる凍結・刻み縮小を行う。途中の未検査候補を出力しない。これにより、途中の修復順序の違いだけで正しい旧軌道が変わることを防ぐ。
