# LC・HC の立体表示

`Topology.Heegaard.draw_heegaard_3d(code, path; crossing_labels=false)` は正の種数の Lickorish Code または Heegaard Code を受け取り、HTML を書いた絶対パスを返す。

```julia
using Topology.Heegaard: read_hc, read_lc, draw_heegaard_3d
draw_heegaard_3d(read_lc("diagram.lc"), "lc.html")
draw_heegaard_3d(read_hc("diagram.hc"), "hc.html"; crossing_labels=true)
```

## 平面配置

[平面描画](heegaard-plot.md)の点列・切断端点を使う。役割なしの入力に対する `plot(lc)` は既存の平面配置器の基準曲線付き経路を公開し、`placement`、`contacts`、幾何検査 `audit`、`success`、`svg` を返す。HC は基準曲線付きの配置を返す経路で `plot(hc)` を使う。自由な α・β の平滑化が K の一部を省く場合は、図全体に `plot(hc.lc)` を使い、成分の色と凡例に HC の役割を反映する。

通過点間の有向区間は、平面の最終交点と端点から再構成した各面の境界から取る。立体化では、すべての成分と交点に同じ写像を施す。切断した基準曲線の両側を展開時に表示し、貼り合わせた状態で一方の写しを表示する。交点の番号は LC のラベルの絶対値である。

## 折りと膨らみ

[平面と立体の対応](heegaard-solid-view.md)と[上下段の規約](../conventions/LickorishCodes.md)に従う。種数 2 以上では、画面下向きの平面座標 y、両列の中線 c に対して v = |y − c| とする。上段を固定し、下段（ℓ⁺）を中線のまわりに奥へ半回転させる。各列で x と v が等しい縁上の点が一致する。曲線と穴の外側に余白を取り、折り線側を含む四隅を丸めた領域を二枚の面の共通の底面とする。

折り終えた面の高さは ±a√(t(2w − t))。a は膨らみの倍率、d は外周と穴の縁までの距離の最小値、t = min(max(d, 0), w) である。d ≥ w の上面の高さは一定値 aw になる。w の既定値は最小の開口半径の 0.9 倍。メッシュ・曲線の中心線・交点はこの高さを共有する。

種数 1 では[長方形の切断図](heegaard-plot.md)の横座標一周を円周方向に巻き、中央から上下の辺までの距離を円環の幅に写す。縦辺の対は同じ偏角、横辺の対は同じ内周を与える。m₁ は円管の断面を一周する。この図での d は内外の円周までの最小距離で、縁幅の単位は長方形の高さの 1/6 とする。

## HTML

ブラウザでファイルを開くと、貼り合わせて膨らませた半透明の曲面が現れる。ドラッグで回転し、ホイールで拡大する。折り角・膨らみ・縁幅・半透明・交点ラベルを画面で変えられる。「再生」は展開状態から始める。交点ラベルの引数は初期表示を選ぶ。

各区間の座標・名前・役割・始点ラベルは HTML 内の SVG に埋め込む。外部スクリプトは three.js r128 と同版の OrbitControls を固定 URL から読み込むため、初回表示には CDN への接続と WebGL 対応ブラウザを使う。

### 立体に表示する曲線の平滑化

平面の公開配置を受け取った後、立体表示用の点列に弧長で対称な区間平均を施す。閉じた曲線は周期的に延長し、切断した曲線は端点について点対称に延長する。これにより開口上の端点を固定し、折れ線の角で接線の向きを連続にする。K を含めた配置の交点符号・相手・巡回順、開口への侵入、空語の曲線の配置を平面描画器の検査で確かめる。検査に失敗した場合は平均の幅を半分にして再試行する。その幅で全体が通った後、各弧について元の幅から順に試し、全体の検査を通る最大の候補を採用する。通過した配置上で交点と区間を求め直してから、曲面と同じ写像で立体へ運ぶ。丸い縁付近は投影後の折れ角に応じて追加の標本点を取る。
