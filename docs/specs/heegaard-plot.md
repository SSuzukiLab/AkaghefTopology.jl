## 公開入口

```julia
using Topology: HeegaardDiagram
using Topology.Heegaard: plot, draw_heegaard

result = plot(diagram; show=:both)
write("diagram.svg", result.svg)
draw_heegaard(diagram, "diagram.svg"; show=:alpha)
```

`plot(hc::HeegaardLayer; show=:both, DEBUG_MODE=false, rounds=24, local_steps=20, log=devnull, reference_alpha=:auto, mark_style=:filled, infinity_face=nothing)`
は、公開型 `Topology.HeegaardDiagram` と同じ型のメソッドである。呼出しは HC の検査、Julia の配置、
Julia の平滑化、最終検査、折れ線 SVG の生成を通る。`Heegaard` がこの generic を export する。
`show` は `:both`、`:alpha`、`:beta` から選ぶ。HC の role を使い、成分名から役割を推定しない。

種数 2 以上の切断表示では、`infinity_face="F14"` のように LC の細分面名を渡すと、
基準曲線網の外側円板内で、その面の内部に無限遠点を配置する。番号は入力の
`_lc_faces` が列挙する面に対応する。面を指定しない場合は従来どおり円板全体の候補から選ぶ。
どちらも候補点から曲線と円周までの最小距離が最大になる候補を使う。
この引数は外側円板を細分する弧の回り方を選ぶ。基準曲線網の別の面を外側円板にする再配置は別の操作である。

## 基準曲線に束縛した α

α の支持が全ての `m1,…,mg`、または全ての `l1,…,lg` と一致するときは、基準曲線を固定し、
β の点列を配置・平滑化する。現在の HC の `standard` 略記は m への束縛であり、その意味を保持する。
l を使う入力は、既存の明示 role 行で l に α を指定する。混在した族、不完全な族、自由な α との混在は、
この簡略経路の定義域に含めない。自由な α・β の入力は従来の general 経路を使う。

`reference_alpha=:auto` は解決済み HC の支持を読む。`:l` と `:m` は入力の支持に対する検査であり、
一致しなければエラーを返す。描画中に α の束縛を交換しない。新しく HC を作るときの l・m の既定値は、
あかげふの判断に属する。表示する固体の選択とも区別する。

m は上下の対応する端点を結ぶ直線で表示し、開口を通る閉じ方を既定の対応に従って読む。
三角形から円への接続を持つ初期配置からは、β と K 全体を共通の座標写像で運ぶ。
写像は y を保ち、各高さで x の狭義単調な区分的アフィン写像を使う。穴の境界と全ての穴の中心線を固定し、
m の経路を同じ二端点の縦線へ写す。中心線の補間点は穴の上下端でも保持する。
経路の頂点・円との交点・円の上下端で分けた各高さ区間で補間点の順序を事前に検査し、
折れ線への離散化後も入力の K に対する交差構造を照合する。

簡略経路の内部では m・n も固定した検査用の曲線として保持する。β と K の全交点について、
符号付きの共有ラベル、β 上と K の各辺上の順、l の切断点の対応と巡回順を検査する。
β の途中の移動には general と同じ局所検査を用いる。固定した基準経路を再標本化・移動しない。
β の交点と入口は、同じ K の辺の中で順序を保って滑ることができる。
種数 1 の切断点は固定する。最終図の交差角は選ばれた α と β について検査し、
非表示の検査用 K との交差角と区別する。

返り値の `reference_alpha` は実際の支持、`initial_placement` は比較用の初期配置である。
`audit.reference` は初期・最終の K に対する照合、固定経路の不変、貼り合わせ後の交差角一覧を持つ。
入口の符号は実際の接線から計算し、上下の切断点が同じ入力ラベルで鏡像対応することを確認する。
`checks.global_gauss` は平滑化中と終了時の照合回数である。簡略経路では配置直後と座標写像後に
各 1 回の入力照合を加え、`reference_placement_gauss=2` と `total_global_gauss` に分けて返す。
終了時の幾何的な全体照合は平滑化器の結果を再利用し、二重に計算しない。
自由な α を K に束縛した表示へ変えるには、曲面の対応と β・印の輸送を備えた別の変換が必要である。
`plot` はこの変換を暗黙に行わない。


`draw_heegaard(hc, svg_path; kwargs...)` は `plot` の結果を SVG へ保存し、絶対パスを返す。
保存前に非零歩数と最終検査結果を確認する。
LC から使う互換メソッドは `draw_heegaard(lc, svg_path; roles, kwargs...)` とし、明示した role から HC を解決する。
役割が不足すれば既存の HC 入力検査で失敗する。ライブラリ内で Python の配置器を呼ばない。
出力契約は SVG である。従来の `png=true` は保存前に未対応エラーを返す。PNG 化は外部の画像化処理が担当する。

## HC の点と円板

`point` と `disk` は [HC 仕様 §3](heegaard-code.md#3-hc-に置く追加情報) の支持を使う。
点は指定された細分面の内部、符号付き交点の直後の弧上、または空語の曲線上に表示する。
細分面の点は最終の境界内で曲線から離れた位置を探す。円板は指定された面の和を薄く塗り、
面どうしが共有する辺を表示上の外周から外す。切断で離れた辺も、LC の同じ辺の逆向きとして相殺する。
`disk` の joining 条件は Koda 変換入口の既存の入力検査に従う。

general で円板の支持が、切断表示に残る曲線で囲まれた面の和なら、円板を外した HC と同じ配置と平滑化を使う。
非表示の基準曲線の辺をはさんで接する細分面をまとめ、平滑化した曲線の交点と弧から円板の境界をたどって塗る。
入力の細分面名は円板の支持として保持する。点の印、空語の成分、非表示の基準曲線を境界とする細分面の指定には、従来の参照曲線を保持する経路を使う。
standard は既存の K に対する経路を使う。
細分面は LC の rotation face の境界を、共有する交点ラベル付きの最終の有向弧へ写して得る。
各弧の端が閉じ、各 LC 辺が二回逆向きに現れることを検査する。
円周の向きと正方形の四隅は既存の切断図の規約から明示する。
回収には平滑化終了時の幾何的照合結果を再利用する。

`mark_style=:filled` は点を黒丸、円板を淡い黄土色の塗りと外周で示す。
`:outline` は点を白抜き丸、円板を破線の外周で示す。色・記号のあかげふの判定は受入資料を読む。
`show` は曲線の族を選び、HC の印は各表示に保持する。
`marks.points` は名前・支持・座標・境界からの距離、`marks.disks` は支持・塗りの経路・外周・ラベル位置を返す。
`marks.audit` に支持回収の検査を返す。無限遠を含む円板の表示はキャンバスで切り、`clipped=true` とする。

空語の曲線を持つ場合は、平滑化入口の配置を固定した比較元とし、各曲線の向き付き面積が
元の `sqrt(eps(Float64))` 倍以上であることと、全ての空曲線の順序対の内外関係が同じであることを、
通常の移動・初期標本化・一括と個別の再標本化で検査する。張力や反発は同じであり、条件を壊す候補を拒否する。
空語のない入力ではこの追加検査を使わない。`audit.empty_places` と `checks.placement_checks` に結果と回数を返す。
歩数0を成功に含めない。

## 種数 1 の境界

general と standard の正方形は、四辺と対辺の対応記号を表示する。
端点は初期の LC の切断点に固定する。初期点が境界上にあり、同じ成分の対応点が対辺の同じ座標に

## 返り値と検査

| フィールド | 意味 |
|---|---|
| `svg` | 選んだ family 表示の SVG テキスト |
| `placement` | 穴、run ごとの独立した点列、role、閉曲線フラグ、交差語 |
| `steps` | 受理した非零移動の歩数 |
| `rejected`, `remeshed`, `history` | 拒否、再標本化、歩ごとの診断記録 |
| `audit` | 下記の最終有限検査 |
| `seconds` | 平滑化関数内の計測。呼出し全体の計測範囲は実行記録に示す |
| `mode`, `production_ready` | 実行した検査経路と通常経路の実装状態 |
| `checks` | 局所の候補検査回数と、入力との全体 Gauss code 照合回数 |
| `timings` | 力、局所検査、再標本化、追加診断、最終検査の秒数 |
| `success` | 非零歩数と最終検査が成立したこと |
| `visual_acceptance` | あかげふによる図の判断。AI agent の数値判定で合格に変更しない |

Gauss code の照合は、各 run 上の交点の順位・符号と、両側で共有する交点の同一性を比較する。
閉じた run の開始位置は巡回移動を許す。同じ交差相手の名前が並ぶだけの照合は用いない。
`audit` は同族交差、線分重なり、穴・外枠への侵入と、配置時からの入口の巡回順・鏡像対応を含む。

`minimum_angle` は交差している 2 線分の鋭角、`stencil_angles` と `minimum_stencil_angle` は
試作の `angles.py` と同じ 3 線分幅の接線角である。両方を記録し、比較時に測り方を明示する。
入口間隔も最終値と検査結果を返す。交差角の 20°は最終図の受入に用い、途中の歩の採否には用いない。
`audit.angle_ok` はこの最終判定を表す。`success` は非零歩数・構造・障害物・入口・最終角度が成立したことを表す。
画像の合否はあかげふが別途判断する。

## 配置と境界

配置は現行 LC 配置器の切断幾何、面の弦、必要な面の Tutte 配置、外側領域の写像を Julia で計算する。
空語の面は既存の Julia LC 回転系を使う。保存済み座標を答えとして返す経路を持たない。
99 件の比較では、点数、厳密な Float64 一致、最大座標差を個別に記録する。
許容誤差の参考集計からあかげふの受入基準を推定しない。

外枠の半径は穴群の中心からの最大距離と穴半径の和を用いて、`2 × extent + 60` とする。
穴がない場合は配置矩形の半対角線を extent とする。種数 1 の正方形の境界検査は矩形を用いる。
外枠は計算上の境界であり、曲面の境界や立体の奥行きを表すものではない。

## 失敗と診断の扱い

通常経路と DEBUG_MODE は同じ平滑化処理を使う。試作 `relax23.py` の局所検査・棄却・凍結・半減・
再標本化の採否に従い、入力との全体 Gauss code 照合は通常経路の最後に 1 回行う。
この検査頻度と途中の角度の扱いは、あかげふから伝えられた第 4 ターンの親の訂正に従う。

候補の局所検査は格子のセルに入る線分対を調べる。交点は run の組の中で前の位置と対応させ、
個数・符号、各 run に保持した隣接交点の順の不等式を検査する。閉曲線の巡回移動を許す。
同族交差・線分重なり・穴と外枠への侵入も検査する。入力の語との照合器は局所検査で呼ばない。

壊れた候補は受理せず、原因の線分の頂点を止めるか移動を半減する。入口を止めるときは鏡像の相手も止める。
再試行でも入口の移動を保ち、他の頂点と同じ比率で縮めて円周へ戻す。入口の対は片方から鏡像として生成する。
各候補で入口の巡回順・最小間隔も検査する。これは正本 §7 の、試作で入口移動が捨てられる欠陥への対応である。
非零の座標移動だけを歩数に数える。
初期の細かい標本化の後に再標本化を 1 回試み、その後は各ラウンドの局所歩の後で試みる。
再標本化の候補は全 run をまとめて検査する。入口へ接続する線分も穴侵入の検査に含める。
まとめた候補が壊れる場合は各 run の候補を順に再検査し、通った候補を受理する。壊れる run の元の点列を保つ。

DEBUG_MODE は、同じ候補が局所検査に通った後に独立した全体照合を加える。
不一致は内部エラーとし、別の軌道へ切り替えない。通常経路と診断経路の数値結果を同じ入力で比較できる。
未対応の入力や role はエラーで示す。

## 力の計算と入口の分散

力の計算には、固定外枠を覆う格子と再利用する作業配列を使う。線分長・弧長座標を一度計算し、
格子セルの線分番号は個数、累積和、連続配列の順に構成する。点から参照する近傍の重複を番号表で除く。
交わる相手が反発の作用距離外にある場合も、移動制限と近接度の計算を行う。
作用しない反発の指数関数と接線内積だけを省く。平滑化の力の式は要件書 §3 を参照する。

入口の分散には円周全体の隣接間隔を使う。正方向の次の入口との角度差を next、前の入口との差を previous とし、
分散の寄与を `(next - previous) / pi` とする。これは隣接間隔と等間隔との差の平方和を減らす向きである。
既存の係数と角度の上限を用い、鏡像の寄与を角度の向きに従って合成する。
位置は対の片方から生成し、相手を `(x, height-y)` とする。形の合否はあかげふの画像判定で決まる。

## 二角形

2026-11-14 にあかげふが、二角形が潰れて描かれる図を「ほぼ破綻」と判定した。対応として、二角形の角にだけ働く
2 つの規則を `hc_plot_forces.jl` に加えた。あかげふは同日、修正後の図を見て二角形の問題の解決を宣言した。
判定資料は `threads/PJ260922/data/261114-bigon-corners/REVIEW.md` にある。

二角形の角とは、同じ 2 本の run の交点 2 個で、どちらの run の上でも隣り合うものである。
語の交点の順から決まり、座標を使わない。平滑化はこの順を保つので、角の組は平滑化の間変わらない。

二角形だけが潰れる理由は次のとおりである。α と β の図では、面の角は α と β が交互に並ぶ。
角が 4 個以上の面は同族の辺を 2 本持ち、同族の反発が全距離で働くので開いたままになる。
二角形の 2 辺は交わる相手同士で、要件書 §3 の 3 により交点の近く（弧長の窓 30）では反発しない。
小さい二角形は全体が 2 つの角の窓に入り、張力だけが残って 2 つの交点が寄る。
交差構造の検査は交点の消滅を止めるが、接近は止めない。

加えた規則は次の 2 つである。

1. 二角形の角である交点では、交わる相手との反発を除く弧長の窓を 30 から 10 に狭める。
   反発の式、作用距離（クリアランスの 2 倍）、接線の内積の 2 乗の重みは要件書 §3 と同じである。
   窓は角の両側で狭める。内側だけ狭めると、角で曲線が折れた。
2. 二角形の 2 つの角の距離 d が 130 未満のとき、その二角形を中点まわりに局所的に拡大する。
   強さは `(130/max(d,3))^2 - 1` である。二角形の 2 辺の上の頂点 v には、中点 c からの向きの力
   `強さ × (v - c) / max(|v - c|, d/2)` を加える。辺の上ではこれは相似拡大である。
   角より外側の頂点には同じ向きの力を、角からの弧長についてのガウス重み（幅 15）で弱めて加える。
   動かすのはその二角形の 2 本の run だけである。

規則 2 を相似拡大の形にした理由は、相似変換が 2 辺とその交点 2 個を一緒に写すことにある。
二角形が標本間隔より小さく潰れた状態からでも、交差構造を変えずに 2 つの角を離せる。
先に試した「2 つの角を互いに離れる向きへ押し、力を各角の近くの頂点へ配る」形は、角が近いと 2 つの角の力が
同じ頂点の上で打ち消し合い、初期配置で角の間隔が 10 未満の二角形を開けなかった。

二角形を持たない図では、どちらの規則も働かず、座標は変更前と一致する。
試した設定の結果は次のとおりである。規則 1 を外すと、潰れたままの二角形が残った。窓を 18 にしても残った。
窓を二角形の大きさに比例して縮める形は、9 連の交点の鎖を悪化させた。
到達を 100 にすると二角形は小さく収まる（角の間隔の中央値が 65 前後、130 では 85 前後）が、
Weeks の全交点を 3 連にした人工例（二角形 36 個）で 1 個が潰れた。
人工例の作り方と結果は判定資料にある。

## 局所的な証明条件の契約

`hc_plot_certificates.jl` の関数は局所的な十分条件である。
返り値 true は下記の前提のもとでの保証を意味し、false はその条件では保証を出せなかったことを意味する。
これらは事前保証を調べる補助関数であり、通常経路の歩の採否には要求しない。
通常経路の採否は上記の局所検査による。

向きと距離の判定は浮動小数点演算の上下界で絞り、境界が判別できない場合は入力座標を正確な有理数として計算する。
整数・有理数から上下界へ変換するときも丸めを外側へ含める。幾何学的な接触を誤差幅で通過扱いにはしない。

`_hp_cert_swept_pair` は最初に離れている 2 線分と、4 端点の全移動経路の長さの上界を受け取る。
各上界が初期線分間距離の 0.3 倍以下なら、移動中の線分間距離は初期距離の 0.4 倍以上である。
呼出し側が渡す値は、最初と最後の点の距離ではなく経路全体の上界でなければならない。
交差を許す相手や、隣接線分の共有端点はこの判定の対象から分け、別の条件で処理する。

`HPCrossingChart` は交点の近傍に固定した可逆な斜交座標と、2 本のグラフの傾き・帯・入口側を持つ。
一方を x 単調、他方を y 単調とし、傾き上界の積を 1 未満にする。帯の外まで各グラフが横断する条件と合わせると、
合成写像の縮小性から交点がちょうど 1 個になる。接線円錐の端の 4 組の向きで、指定した角度下限も検査する。
同じ頂点数の開始・終了点列が同じ固定条件を満たせば、各頂点の直線運動でも線形不等式が保たれる。
交点が標本頂点を通ることを許す。円周運動、他の交点との順序、第三の線分との接触は呼出し側の別条件である。

`_hp_cert_graph_delete` は 3 頂点の中央を削除する局所条件である。中央の頂点が新しい弦に沿う順序を保ち、
旧点列と弦の間の三角形が禁止線分・穴に触れないことを正確に検査する。共有する両端との孤立した接触だけを許す。
この場合、旧グラフから弦への補間で禁止対象を横切らない。交わる相手は別途、交点近傍の条件で処理する。
呼出し側は外枠の凸性、閉曲線の巡回添字、交点近傍、初期状態の妥当性も検証する必要がある。

`_hp_port_collar_certificate` は、円周上の入口とその次の頂点を結ぶ線分の半径方向余裕の下界を使う。
現実装は入力有理数として厳密に円周上にある入口だけを受け付ける。
三角関数で生成した Float64 座標に、円周上という前提を自動的に付与しない。
角度を状態として持つ入口と、その座標の上下界を扱う接続は別途必要である。
