# LC と HC の move: データと共通の書き換え

Status: 2026-11-09 の仕様草稿。LC・HC の名称と HC の形式は所有者確定。カタログのスキーマと適用手順は本書の提案<br>
Scope: LC の同位、Dehn twist、HC の handle slide と安定化、固定した K の下での置き換え<br>
Authority: 正本のチェックアウトは研究リポジトリの `lib/topology.jl`。move の共通実行経路の実装は次段階。名称と仕様の正本への統合は 2026-11-09 に実施

## 1. 結論と参照の基準

move は専用ファイルのデータで定義する。実行経路は、カタログ、適用箇所の探索、固定した witness、共通の書き換え、対応の輸送の順とする。種類ごとの公開関数は、カタログの行と入力選択を渡す薄い入口とする。語の照合、巡回の接続、ラベルの更新は、共通経路が一度だけ持つ。

[VirtualLink の move 仕様](virtual-link-moves.md) の `MovePattern` を、有限の語の断片を記録する型として再利用する。曲面上の支持、成分の意味、可変長の展開、印の輸送は追加データに置く。曲面の変更は、有限な局所曲面と境界の貼付けとして記述する。

本書のコードと仕様の正本は、研究リポジトリの `lib/topology.jl/` である。研究資料の位置は、明記した場合に限って研究リポジトリを基準とする。同じ仕様ディレクトリの [LC 仕様](lickorish-code.md)、[HC 仕様](heegaard-code.md)、[用語の正本](heegaard-terminology.md)、[Koda 変換仕様](heegaard-koda-conversion.md) に従う。

LC は曲面・K・語・place を持つ。HC は LC と、明示する role 行、disk などを持つ。HC の `.hc` から `.lc` を参照する形式、非 K 成分への役割の全指定は、所有者が採用した形式に従う。

## 2. 実コードで確認した再利用の範囲

2026-11-09 の正本チェックアウトを読んだ。次表は実装の部品の責務を示す。数学的な move の成立範囲は §8 で別に定める。

| 既存の部品 | 確認した挙動 | LC・HC での扱い |
|---|---|---|
| `src/helpers.jl::MovePattern` | gauss、orientation、capacity、端の記号、頂点数、辺重みを持つ | 有限な before・after の語の射影を格納する。LC の orientation は全交点で +1。重みは使用しない |
| `make_move_data` | helpers.jl の配列と生成規則からカタログを作る | 既存の o-graph 用カタログを維持し、LC・HC の専用 JSON を読む入口を追加する |
| `src/moves.jl::_pattern_occurrences`、`_cyclic_occurrences` | 閉成分の末尾と先頭をまたいで照合する | LC の巡回語に再利用する |
| `_location_products`、`_locations_compatible` | 複数の照合位置を組み合わせ、重複する区間を除く | 成分と K の条件を足した同じ探索へ使う |
| `MoveCandidate` | 頂点対応、before・after、方向、具体的な位置を保持する | 語の部分 witness として使い、曲面・成分・印の対応を外側のレコードに加える |
| `_simple_pattern_rewrite` | 同じ capacity の非巡回区間を直接置換する | 既存の高速経路として使う |
| `_reconnect_pattern`、`_move_segment_paths` | 外側の語片と target の断片を port で接続する。巡回、分裂、併合を扱う | 共通の接続処理として再利用し、各語片の由来を返すよう拡張する |
| `_vertex_maps` | 追加・除去と密な番号への付け替えを行う | LC では K∩K の固定ラベルと明示された生存対応を優先する、ラベル方針を追加する |
| `movable(v::VirtualLink,type)` | 種類と頂点数で表を選ぶ。通常の空断片は探索から除く。PS 等には専用の挿入経路がある | 供給した pattern 対と空の occurrence を受け取る共通探索へ拡張する |
| `move(v,candidate)` | 固定した candidate を現在のカタログと再照合してから適用する | 外部 witness の認証を再利用する。内部で新しい適用箇所を選び直す処理は加えない |
| `_apply_pattern_move!` | ラベル更新、直接置換または再接続、VirtualLink への保存を行う | 語片の書き換えを共通核へ分離し、LC・HC はそれぞれの保存先へ同じ結果を接続する |

現状の公開 `movable` と `move` は、固定された種類の分岐と VirtualLink の保存先を持つ。LC カタログをそのまま渡すために必要なのは、供給した pattern 対、符号の意味、ラベル方針、保存先を共通核の入力にする変更である。LC 用に語の照合器や巡回接続器をもう一組作る必要はない。

LC の passage sign は曲面の回転を、o-data の passage sign は over/under を記録する。既存の MP・PS の行を LC の同位の表として使う操作は数学的に定義されていない。LC の空語には place がある。挿入位置は witness の gap として指定する。語へ `0` を追加して挿入位置を表す処理は採らない。

HC の領域係数 weight は、VirtualLink の辺重みとは別のデータである。既存の Float64 の辺重み輸送を HC の整数 2 次元鎖へ流用する根拠はない。HC の係数は局所曲面の対応で輸送する。

## 3. データの置き場所と形式

専用データは JSON とする。既存の JSON3 を使い、Julia のコード、式の eval、関数名、任意のコールバックをファイルへ埋め込む形式は採らない。次のパスは正本チェックアウトを基準とする配置案である。

| パス | 内容 |
|---|---|
| `data/heegaard/moves/catalog.json` | schema version、全行への相対参照、行の状態と出典 |
| `data/heegaard/moves/lc/isotopy.json` | 二角形、K の頂点越え、入力曲線の交点の K 越え |
| `data/heegaard/moves/lc/dehn-twist.json` | 円環の局所断片、周期貼付け、整数回の展開規則 |
| `data/heegaard/moves/lc/fixed-reference.json` | 固定した K の下で許す、具体的な局所曲面の対 |
| `data/heegaard/moves/hc/handle-slide.json` | 同族の二曲線、band、境界の追跡、役割と印 |
| `data/heegaard/moves/hc/stabilization.json` | 円板と一穴トーラスの対、追加する α・β、基準網の同定 |
| `data/heegaard/moves/shared.json` | 境界 port、局所曲面、対応、反復の共通スキーマ |

今回の実物の案は、研究リポジトリ基準の `.research-scratch/PJ260922/ld-koda-spec/261109-data-proposals/` に置く。カタログの存在、局所表の転写、一般の正しさの証明、実装の受入を、それぞれの状態として記録する。

### 3.1 一つの行が持つ情報

| 欄 | 定義 |
|---|---|
| `id`、`schema_version`、`layer` | 安定したカタログ参照、形式の版、LC または HC |
| `source`、`target` | 同じ外部 port を持つ有限な曲面と曲線の断片。語の射影は MovePattern の欄で記す |
| `bindings` | 局所曲線から実成分への対応。K、K の辺、同族、異族などの条件 |
| `support` | 円板、円環、band、一穴トーラス等の有限 PL 表現と、入力曲面への埋込み |
| `crossings` | 生存、生成、除去の対応。K∩K の固定ラベルは pin する |
| `boundary` | port の順序、向き、辺パラメータ、source・target の貼付けの全単射 |
| `expansion` | 入力から得た有限列を索引として、どの断片を何回複製して接続するか |
| `applicability` | 語の照合に加えて入力支持が満たす条件。条件名は共通の有限な語彙から選ぶ |
| `correspondence` | 曲線、交点、辺片、局所曲面の対応と、恒等に保つ外部 |
| `transport` | place、HC の役割、disk、point、weight の支持の輸送規則 |
| `relation` | 同位、指定した曲面同相、handle slide、安定化など、主張する数学的関係 |
| `inverse` | source・target の交換と、境界・対応の逆。反復の符号と順序の逆転 |
| `evidence`、`status` | 原典と locator、agent の論証、未確定の欄、実行可能な範囲 |

曲面の断片は向き付き多角形または三角形と、全境界成分の貼付けの表で与える。単なる境界語は補領域の種数と複数境界を決めない。局所曲線は有理座標の PL 弧か、向き付きセルの列で記す。座標は位相的な操作の支持を与え、描画の配置を選ばない。

反復は有限集合の列挙、有限列の複製、順序の反転、端の貼付け、整数係数の有理アフィン写像に限る。条件に応じた向きの違いは、符号をキーとする有限表で与える。実行器は move 名を見て語や接続を作らない。

## 4. 探索と witness

公開名の案は既存と同じ `movable(input, catalogue_entry; selections...)` と `move(input,witness)` とする。LC・HC に応じたメソッドは、同じ語片の探索・接続核へ渡す。返却値は新しい LC または HC、逆方向の witness、構成時の対応である。

探索は入力を変更しない。LC の語と place、HC を使う場合は役割と印を一度入力検査する。カタログの source を展開し、巡回語の出現位置を組み合わせる。その後、実現した曲面上で支持の埋込み、内部の交点、境界の貼付け、役割、印の輸送条件を判定する。

局所二角形と三角形は入力の有限なセルから列挙できる。一般の支持曲線や band の同位類は無限にある。この場合、入力は具体的な支持の有限 PL 列、または有限な探索候補の集合を与える。`movable` は、その探索範囲と採用した候補を返す。探索範囲の上限を、数学的な move の存在条件に置き換えない。

witness は次を固定する。

| 対象 | 固定する値 |
|---|---|
| 入力 | LC・HC の値の識別、カタログの版と行の digest |
| 語 | 局所ラベルから実ラベルへの写像、成分、巡回開始位置、区間、gap の occurrence |
| 支持 | 曲面のセル、全境界、向き、貼付け、選んだ band・円環・曲線の経路 |
| 展開 | 反復の索引列と端の対応、新ラベルの割当て |
| 印 | 各支持の像、必要な代表点や分割、HC の追加選択 |
| 逆操作 | 逆の局所埋込みと対応。入力全文の保存を要しない局所データ |

外部から受け取った witness は、現在の入力と同じ局所条件を満たすことを認証する。固定済み witness の適用では、別の出現位置を探索して代用しない。複数候補は候補集合として返し、選択した一件だけを実行する。

## 5. 共通の書き換えと対応

共通実行器は、witness の区間で語を切り、外部の語片を保持する。source の局所片を除き、target の片を外部 port で貼る。capacity の接続グラフを辿り、閉じた語を組み立てる。新しい空語成分には、その構成から place を付ける。曲面の局所片も同じ外部境界で貼る。

生成と除去は、カタログが指定した交点の対応で行う。既存の K∩K の定数ラベルは保ち、それ以外のラベルの付け替えは写像として返す。安定化のように種数が変わる行は、新しい標準 K のラベルと旧基準網の像を別に返す。成分名と role の対応は、再接続後の成分の由来から付ける。

出力では K を LC の固定順に置く。生存する非 K 成分は元の宣言順を保ち、新成分はカタログの宣言順に続ける。分裂・併合する行は、どの成分へどの名前を与えるかもデータで指定する。再接続器が返す配列の順だけで role を割り当てない。

対応は曲線、交点、向き付き辺片、局所曲面のセル、全境界の写像として返す。交点の生成・除去では部分全単射となる。handle slide では新曲線から元の二曲線と band への構成の対応になる。安定化では外部の同一視と付加・除去した一穴トーラスの対応になる。すべてを一つの曲面同相と呼ぶ契約にはしない。

HC の role は成分の対応へ沿って運ぶ。disk、point、weight は支持の像から新しい LC の細分領域と弧へ書き戻す。F 番号の整数をそのままコピーする操作は輸送を意味しない。細分した補領域の係数は整数の鎖として制限し、貼り合わせには接合する辺の係数の整合を使う。

上の層の支持が変わる場合、カタログと witness がその像を構成できることを適用条件にする。新しい disk を別に選ぶ場合は、それを追加の選択として明記する。joining 条件の保持を主張する行は、その条件を局所構成で保つ根拠を持つ。印の像が足りない要求には、必要な輸送指定を返す。元の HC を保持したまま止まる。

## 6. 各 move のデータ

### 6.1 LC の同位

| 手 | source・target のデータ | 適用条件と保存するもの |
|---|---|---|
| 曲線と K の辺の二角形 | 二本の弧と二交点を持つ円板、二交点を取り除いた円板。K の弧は同じもの | 二角形内部と境界に他の事象がなく、K の頂点を含まない。入力曲線の自己埋込みと入力曲線どうしの交点を保つ |
| 曲線が K の頂点を越える | K の二曲線と入力曲線の三角形の前後。K∩K の頂点は同じ局所ラベル | 三角形内部が空。K の二本の弧とその交点を固定する |
| 入力曲線の交点が K の辺を越える | 同じ三角形の表で、一本を K、二本を入力曲線へ束縛する | 入力曲線どうしの交点を生存対応で保ち、K の辺は固定する |

二角形の具体的な一行は、source の語が `C:[-1,+2]`、`K:[+1,-2]`、orientation が `[+1,+1]`、target が二つの空断片である。K を `(x,0)`、C を `(-2,1)→(0,-1)→(2,1)` とし、target の C を `(-2,1)→(2,1)` とする局所円板で実現する。交点は x の昇順に付ける。空断片の位置は端の port で固定する。

三角形の一行では、局所ラベル 1 を A∩B、2 を A∩C、3 を B∩C とする。

```text
source A:[+2,+1] B:[+3,-1] C:[-3,-2]
target A:[+1,+2] B:[-1,+3] C:[-2,-3]
orientation:[+1,+1,+1]
```

A は上向きの縦線、B は右上向きの斜線、C は右向きの弧とする。C の中央部分を y=−1 から y=+1 へ移す。C の両端は同じ外部 port へ接ぐ。K の頂点越えでは A と B を K に、交点の K 越えでは A だけを K に束縛する。向きの他の組は、局所曲線の向きと passage sign の変更を、LC の枠の規約で導いた表として追加する。o-graph 用 `_reverse_template` の crossing orientation 反転を LC に適用する根拠はない。

状態は、局所 PL モデルの agent の証明である。任意の LC への適用は、境界と向きを保存する円板の埋込みを witness が返すことで正当化する。

### 6.2 LC の Dehn twist と逆

支持は向き付き円環 A=(R/Z)×[0,1] と、その入力曲面への埋込み φ である。正の枠は (∂s,∂t) とする。整数 q に対し、円環の写像を次式で定義する。

```text
F_q(s,t) = (s+q*t mod 1,t)
F_0 = identity
F_q ∘ F_r = F_(q+r)
F_q^(-1) = F_(-q)
```

q=+1 という名称の符号はこの式で固定する。LC の既存例との対応は、同じ向きの円環の同定と、付随する同位を含めて照合する。P28 の語の認識で式の符号や適用曲線を決める経路は置かない。

データは、周期方向の貼付け、基本四角形、整数係数のアフィン行列 `[[1,q],[0,1]]`、q の反転、基本断片の複製と deck 変換の規則を持つ。共通の展開器は |q| と入力弧の有限列から有限な片を作る。s+q*t が整数を横切る位置で分け、周期境界を再接続する。

対象曲線の A 内の全 PL 弧を写す。円環の同じ境界へ戻る弧、巻いた弧もその列に含める。F_q の写像後の片と、固定した K・その他の曲線を共通細分へ載せ、横断交点と巡回順を一般の交点抽出で得る。増える交点の数を定数にしたり、常に m_i と n_i を一回だけ足す処理を一般の規則にしない。

有限曲面の実現、共通細分、語の抽出は、LC の実現と Koda の基準網を重ねる工程が使う共通の契約へ接続する。凸多角形の交差や三角形分割などは、既存ライブラリを再利用する。move ごとの配置器やメッシュ最適化を新しい操作の核にしない。

全入力曲線へ同時に写像を適用する行と、指定した部分族へ適用する行を、データの `acted_components` で区別する。全曲線・印へ同じ写像を施す場合には、K を忘れた Heegaard diagram が曲面同相で対応する。部分族だけを動かす Dehn twist は、HC の三次元多様体を保つとは限らない。HC で使う場合は役割と同族内の非交差も適用条件にする。

逆は q の符号を反転し、同じ円環と作用成分、輸送の逆を使う。F_q の基本領域への降下、境界で恒等となること、逆写像の式は agent の証明である。可変長の語への抽出を含む一般の実装の受入はテストで行う。

### 6.3 HC の handle slide

データは、異なる同族曲線 a_i、a_j、向きを持つ埋め込まれた band、両端の接続、幅と押し出す側を持つ。band の内部は同族の曲線を避ける。K と異族曲線との横断交点の列は、反復する局所断片として記録する。

source は二つの曲線と band の近傍、target はその pair-of-pants の第三の境界で a_i を置き換え、a_j を保つ配置である。境界の走査は、曲面の向きと外部 port から共通の境界追跡器が行う。種類固有の関数で a_j の語を手作業で挿入する経路は置かない。

逆は同じ pair-of-pants の対の向きを反転して得る。逆の band と押し出した曲線の対応は witness に残す。完全切断系の disk slide は同じ handlebody を与える。これが HC の多様体を保つ根拠であり、状態は agent の論証である。disk と他の印の保持は §5 の輸送条件に従う。

### 6.4 HC の安定化と逆

source は曲線のない円板、target は一穴トーラスと、その内部で一回横断する新しい α_0・β_0 である。境界は同じ一つの円周へ接ぐ。データは曲面の全貼付けと α_0・β_0 の局所語、向き、役割を持つ。種数の変化は +1 である。

種数の変更に合わせ、標準 K_g から K_(g+1) への実現上の対応と、新しい基準曲面への同定も入力選択に持つ。K の追加の交点を共通の抽出器で計算する。語に新しい l・m・n の定数行を足すだけの処理は、古い曲線との位置関係を決めない。

逆の適用箇所は、他の入力曲線を含まず、α_0・β_0 が一回横断する一穴トーラスの支持として指定する。支持の境界と、切断して円板で埋めた曲面の対応を固定する。これを逆向きの同じデータで置換する。より広い destabilization の探索は、他の move を組み合わせた別の探索課題として記録する。

新しい一対が表す種数 1 の分解は S³ の標準分解であり、これとの連結和は元の多様体を保つ。状態は agent の論証である。種数変更後の K と印の輸送の完全な有限表は、データの確定項目である。

### 6.5 K を保つ置き換え

source と target は、同じ局所曲面、同じ境界 port、同じ K の部分グラフを持つ。K の辺と頂点は、その埋込みで一致させる。置き換える入力曲線、保存する crossing、生成・除去する crossing、主張する関係を具体的な行へ書く。

K の保持だけから同位や多様体の同値は導けない。同値を主張する行には、局所同位、曲面同相、または Heegaard の操作としての根拠を付ける。任意の before・after を受けて同値を宣言する汎用行は定めない。具体的な関係が未指定の行はカタログで未解決とする。

## 7. 逆方向と保存データ

逆方向は source・target の交換、境界写像と対応の逆、展開の逆順から得る。曲線や交点を除く操作は、逆を構成するのに必要な局所片とラベルの対応を witness に残す。適用後の対象に対して逆の適用可能性を認証する。

逆の幾何学的操作、元のラベルへの復帰、元の文字列への復元は別の契約である。元の文字列を要求する保存機能は原文の bytes を保持する。幾何学的な逆操作は、それを返却する代わりに実際の逆向きの局所置換を行う。

## 8. 既定経路と受入

既定経路の検査は、外部入力、カタログの形式、適用可能性、外部 witness の認証だけとする。構成時の対応は実行結果の一部として通常経路で返す。出力全体を再実現する検査、Euler 標数や切断系の独立再計算、逆操作の試行は DEBUG_MODE とテストへ置く。

| 試験 | 入力と期待値 |
|---|---|
| 二角形 | §6.1 の二つの語片を、同じ境界の円板へ埋め込む。二交点が消え、K の弧と外部の語片を保つ。逆で同じ局所配置への対応を返す |
| 三角形 | §6.1 の source と K の束縛を入力する。target の三つの語と交点の生存対応を返す。両端をまたぐ巡回位置でも同じ結果 |
| 反復 twist | 一つの円環に横断する弧を 1、2、5、17 本置き、q=0、±1、±3 を使う。F_−q∘F_q は円環の同じ点と弧へ戻る。語の具体値は K と円環の埋込みを固定して算出する |
| handle slide | 明示した同族二曲線と band。target は pair-of-pants の第三境界。逆 band で元の切断系への構成の対応を返す |
| 安定化 | 明示した空円板と、標準 K の新しい同定。種数 +1、追加する各族一本、両曲線の交点一つ。逆で外部の対応を返す |
| 印の輸送 | K の細分領域が分裂・併合する支持。point と disk の支持、整数係数を構成時の対応で書き戻す。輸送指定が足りない入力には不足を返す |
| LC と多様体 | 部分族だけの Dehn twist は、多様体の同値を自動付与しない。たとえばトーラスの α=a、β=b から β′=a+2b を得る向きの twist では、交点行列の行列式は 1 から 2 へ変わる |

研究リポジトリ基準の `threads/PJ260922/code/hc_operations*.py` と `hc_twist.py` は、入力例と局所操作の材料である。`src/heegaard/marked_moves.jl` の三角形・頂点同位、`marked_slides.jl` の band と pair-of-pants、`marked_stabilization.jl` の支持の切除と貼付けは、構成と輸送で必要な情報の材料である。これらの種類ごとの実装を、新しい種類別の語の処理として移植することは仕様の根拠にしない。

`marked_twists.jl` の全曲線への区分的アフィン写像と `marked_twist_words.jl` の有限写像の合成も材料とした。全曲線を同時に動かす場合と部分族だけを動かす場合を分けること、周期境界での対応と逆の写像を記録することを本書へ取り込んだ。

## 9. 確定項目

共通経路と再利用の境界は、本書の設計提案である。二角形・三角形の一つの向き、円環の写像、反転の規則は具体的に記した。全向きの表、band の全接続、安定化後の標準 K への同定、印を保持する局所輸送の行は、データの転写と一般の成立の確認が残る。

任意の支持曲線や band の全探索、任意の二つの LC の同位判定、任意の固定 K の置き換えの同値判定は、ここで定めた一回の move の適用を越える。各探索の有限な入力範囲を記録して扱う。

次の確定作業は、専用データの各行を、この共通経路の入出力と数学的関係に照合することである。親が原典・局所図とデータを確認した後、Composer が共通核の差分を実装する。
