# U(R) MST evaluator

```julia
H = URAlgebra()
value = Z_MST(v, H)  # Rational{BigInt}
expr = invariant_expression(v, H)
value == evaluate_invariant(simplify_invariant(expr; strategy=:determinant))
```

This backend owns only the trace matrix and its exact evaluation. It neither
constructs nor mutates a URDiagram and performs no diagram reductions or plotting.
The involutory specialization uses the real Gauss word and vertex signs, not
integer edge weights; supplied weights are preserved.

The operator word is the reverse of the real Gauss traversal. Rotate it to
start at a positive visit, and let j(x) count positive visits up to x. Set
M[j(v),j(-v)] += sign(v), with vertex sign in +/-1. The defining matrix is
M + I - P, where P advances a row cyclically. The signed trace convention is
-1/det(M+I-P). Rational arithmetic avoids floating determinant artifacts.

Currently supported: one nonempty closed component with paired real visits,
and a nonsingular trace matrix. Unsupported multiple components and singular
matrices raise explicit errors; no prescription for divergent traces is inferred.
Strategies :auto, :determinant and :none have identical values; simplification
copies the expression because no separate rewrite is needed.

The historical `ur_prime_invariant` used the unreversed word. It now delegates
to this backend and returns exact rationals. `ur_invariant` still uses
URDiagram. Neither is called by this backend.

Source: owner's P260309AGTC2.pdf, page 1, "Proof sketch for H = R[x]",

The poster supplies the matrix formula, its cyclic correction and the signed
1/|H1| statement. The conversion from stored traversal to operator word is
the repository adapter convention, also used by `vl_to_urdiagram`; the poster
does not literally prescribe reversing a stored Gauss array.

Regression scope: abalone sums 1..5 give -1,+1,-1,+1,-1; registered L(2,1),
L(3,1), L(3,2), Poincare examples have magnitudes 1/2,1/3,1/3,1.
This finite agreement does not prove general invariance or classify framings.
